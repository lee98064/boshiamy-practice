# 蝦米練習室：實作規劃

## 目的與預設

為學習與重新熟悉嘸蝦米的人提供直接可用的練習桌。預設輸入英文字根，不需要安裝輸入法。形、音、義練字根對應；詞語、成語、文章逐字輸入建議碼；尚未核對的自訂文字保留並標示為一般碼表練習。字根與完整字碼必須在介面上明確區分。

## 設計

2026-09-28 比對本機 frontend-design 與 anthropics/skills 上游。上游最近一次變更為 2026-09-03，commit `41bbe19d1a1a7eaab5e7bb9050a417e5c6cffc8f`，內容不同。已閱讀並採用新版；未改動使用者全域 skill。

核心色票：霧白 `#f5f7fc`、紙白 `#ffffff`、墨藍 `#202f4d`、鈷藍 `#3659e3`、粉筆藍 `#e9efff`、鼠尾草 `#507669`。警示另用 `#ad3d45`。
字體：練習漢字使用系統 Songti TC / Noto Serif CJK TC 襯線；操作介面使用 PingFang TC / Microsoft JhengHei 無襯線。英文字根鍵帽使用系統 monospace，僅用於實際鍵盤字碼。
版面以文字左對齊、練習字格置中。桌機左側固定導覽，主區域練習桌搭配右側學習解說；手機底部導覽與可點擊鍵盤。

候選 A：課程卡片首頁 → 必須先找課程才能練；候選 B：直接顯示字格和答案欄 → 符合每天打開就練的任務。採 B。

```text
桌機： [ 導覽 ] [ 標題 / 今日進度                  ]
       [      ] [ 形 音 義 詞語 成語 文章          ]
       [      ] [ 字格 + 答案 + 鍵盤 ][ 學習解說   ]
       [      ] [ 練習說明          ][ 本回合統計 ]

手機： [ 品牌 / 安裝 ]
       [ 標題 / 分類可橫滑 ]
       [ 米字格 / 答案 / 鍵盤 ]
       [ 學習解說 ]
       [ 練習 查碼 字本 設定 + safe area ]
```

自評修訂：不使用裝飾編號、行銷 hero、漸層或相同卡片堆疊；唯一視覺焦點是實際可互動的米字格。右側示意字根有教學用途。所有統計來自使用者操作。

字根作答更新：網頁鍵盤使用與米字格呼應的小方格，依題目碼數預先留空；沿用墨藍、霧白與等寬字碼字體，當前空格只以藍色邊線標示，不使用閃爍游標。另提供鍵盤輸入的一般輸入框與中文字模式。選擇三個明確的作答工具按鈕，避免兩組互相影響的模式切換。方格封裝為 `CodeAnswerSlots.vue`，保留在練習頁使用，App 外框不承擔作答邏輯。

## 功能與工程

- Vue 3 Composition API + TypeScript + Vite；Vue Router hash history 避免 Pages 深連結 404，四頁分離，App 只保留外框。
- 六類練習、提示、跳過、重新練習、題數、正確率、用時、錯題回顧。
- 中文查字碼、字碼反查、收藏、本機 UTF-8 CIN / JSON 匯入。已確認免費非商業用途，採用公開 liu57a_ersu 舊版碼表，共 13,563 字元；保留來源聲明，不宣稱為目前官方完整字庫。
- 練習紀錄 localStorage；較大的匯入字典 IndexedDB。失敗要告知，資料不離開裝置。
- PWA 靜態檔預快取，更新由使用者確認，不打斷練習。
- iOS standalone / apple-touch-icon / viewport-fit=cover / 四邊 safe-area / dvh / 不禁用縮放。
- GitHub Actions 檢查與部署，從 configure-pages 輸出取得 base path。
